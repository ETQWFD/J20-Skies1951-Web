# 长空·1951 · 网页版 / J-20 SKIES OVER KOREA (Web)

抗美援朝主题 3D 纪念游戏《长空·1951》的**网页版**，打开浏览器即可玩，含「空战 · 歼-20」与「陆战 · 步兵冲锋」两种模式，电脑和手机分别做了专属版本。

- 入口（自动推荐你的设备，并可选择「空战 / 陆战」模式）：https://etqwfd.github.io/J20-Skies1951-Web/
- 电脑版：https://etqwfd.github.io/J20-Skies1951-Web/pc.html
- 手机版：https://etqwfd.github.io/J20-Skies1951-Web/m.html
- 直达：`pc.html?air` / `m.html?air`（空战）、`pc.html?ground` / `m.html?ground`（陆战选关）、`pc.html?ground&s=0..3`（直达战役）
- 桌面完整版（Windows EXE / Android APK / 局域网联机 / 21 场陆战战役）：https://github.com/ETQWFD/J20-Skies1951

## 联机战场（v1.9.7 · 局域网 · 电脑/手机浏览器同房间）
入口 `net.html`（首页第 3 张卡片）。采用**主机权威**：点“创建房间”的浏览器承担战局（30 个美军 AI、命中与血量判定），其余人点“加入房间”并肩作战，位置/血量/击杀实时同步。

> 浏览器不能直连桌面端的裸 UDP；GitHub Pages 也只能托管网页、不能跑联机服务。因此联机走 **WebSocket**，需用随附的零依赖服务器（仅 Python3 标准库）在**同一 Wi-Fi 的一台电脑**上启动：
> ```
> python3 server.py            # 默认 8765 端口，可加参数改端口
> ```
> 启动后终端会打印类似 `http://192.168.x.x:8765/net.html`，房主和战友都用这个地址打开网页（不要用 GitHub Pages 地址联机）。电脑用键鼠、手机用触控，可混房。
> - 桌面 EXE/APK 与网页三端互通：需把桌面 C 端 UDP 也改造成同一 WebSocket 协议并出新版（规划中）。
> - 跨网段/互联网联机：需要一台公网服务器运行该 WebSocket(wss) 服务。

## 玩法
驾驶歼-20 在硝烟弥漫的朝鲜上空迎击一波波 F-86 机群与地面高射机枪阵地：
- 机炮（按住连射，带炮口焰与可见曳光弹）、可锁定的追踪导弹（带实体模型）；
- 敌机 AI 朝玩家转向、点射、不会撞地；地面高射阵地转管对空射击，可被机炮/导弹摧毁；
- 柏林噪声(fBm) 生成起伏山地、雪线、焦土弹坑；程序化青松/雪杉/焦黑断木；
- 硝烟渐变天穹、指数灰雾、地面炮火与黑烟、ACES 电影色调映射；
- 地形前瞻防撞、相机不会穿进地里、树干实体碰撞；
- 波次、得分、击杀播报、暂停/继续/重开，切后台自动暂停。

## 陆战 · 步兵冲锋（v1.9.5 新增，第一人称）
随志愿军战友夺取前方高地、肃清全部美军：
- **重新建模的士兵**：约 1:7.5 头身比例、髋/躯干/装具/背包/可动肩肘髋膝关节；志愿军土黄棉布军装+棉帽红星，美军橄榄绿军装+M1 钢盔；行进摆腿屈膝、身体起伏、瞄准时双臂端枪、倒地动画；
- 莫辛-纳甘狙击步枪（5 发，爆头一击毙命，15 倍镜）、AKM（100 发自动）、大刀与拳头近战、手雷（长按蓄力显示抛物线，可误伤）；
- 头/胸/腿三段命中判定，爆头高伤、腿部减伤；红蓝血条（敌红我蓝）、暗红倒地痕迹；
- 美军向玩家与战友点射、敌我互射；战友 AI 成队冲锋；清空高地即升起五星红旗胜利结算；
- 沙袋掩体、环形阵地、地面炮火黑烟；PC 实时阴影，手机用接触阴影保持流畅；
- PC：WASD 移动、Shift 冲刺、空格跳、鼠标视角、左键开火、右键开镜、1/2/3/0 切枪、长按 M 手雷；
- 手机：左摇杆移动、右半屏视角、火/镜/跳/雷/换/暂停虚拟按键。

## 技术
- `engine.js`：空战引擎 + 模式选择/路由（`?air` / `?ground`），仅依赖 Three.js r160（unpkg CDN importmap）；
- `core.js`：空战/陆战共享的世界构建（地形、天穹、光影、雾、树、火光、地面高度）与士兵/枪械/红旗程序化工厂；
- `ground.js`：陆战第一人称模式（移动、射击、命中、AI、手雷、HUD、触控）；
- `net.html` + `netplay.js`：联机战场（主机权威 AI/命中、快照同步、真人玩家插值、触控复用）；
- `server.py`：零依赖联机服务器（Python3 标准库 HTTP 静态托管 + WebSocket `/ws` 中继）；
- 全部人物/枪械均为**原创程序化模型**，无任何第三方美术/模型资源；
- `version.txt`：版本轮询，发布更新后页面顶部会出现“发现新版本，点击更新”；
- 单局全部状态机/弹道/粒子为实时计算。
