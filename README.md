# 长空·1951 · 网页版 / J-20 SKIES OVER KOREA (Web)

抗美援朝主题 3D 空战《长空·1951》的**网页版**，打开浏览器即可玩，电脑和手机都支持。

- 在线试玩（GitHub Pages）：https://etqwfd.github.io/J20-Skies1951-Web/
- 桌面完整版（Windows EXE / Android APK / Linux 源码）：https://github.com/ETQWFD/J20-Skies1951

## 玩法
驾驶歼-20 在硝烟弥漫的朝鲜上空迎击一波波 F-86 机群：机炮、锁定导弹、地形规避；柏林噪声生成的起伏山地、硝烟雾、地面炮火与黑烟。

## 操作
- 电脑：`W/S` 油门，`↑↓` 俯仰，`A/D` 滚转，`Q/E` 方向舵，`空格` 机炮，`F` 导弹
- 手机：左下虚拟摇杆（俯仰 / 方向舵），右半屏滑动控制滚转，右下「火 / 弹」按钮
- 低速会失速，近地自动辅助拉起

## 技术
单文件 `index.html`，仅依赖 Three.js（CDN）程序化建模，无美术资源；开火、导弹追踪、敌机波次、爆炸与烟柱均为实时计算。
